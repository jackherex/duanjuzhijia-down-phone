## 常见问题

**提示「应用未安装」怎么办？**
常见有两种原因：一是手机存储空间不足；二是手机较老、只支持 32 位应用。本安装包是 64 位，绝大多数 2018 年之后的安卓手机都能装。

**会覆盖我原来装的短剧之家吗？**
会直接覆盖升级，**收藏和观看进度都保留**，不用先卸载。

**手机和电脑之间怎么同步？**
在「设置」里配置「设备互联」或 WebDAV（坚果云、群晖、OpenList 都行），两台设备填**同一套**配置即可。电脑版可以在设置页生成二维码，手机版扫一下就能自动填好。

**一定要联网吗？**
要。看剧本身需要联网；已经下载到本机的剧集可以离线看。
